# BiliTool.Vn HL7 v2.5.1 ORU Profile

## Transport

```http
POST /api/v3/hl7/v251/oru-r01
Content-Type: application/hl7-v2
X-API-Key: <tenant-client-credential>
Idempotency-Key: <MSH-10>
```

`Idempotency-Key` phải bằng `MSH-10`. Retry cùng MSH-10 và cùng message trả lại cùng ACK. Message khác dùng cùng key bị từ chối bởi idempotency layer.

## Required message structure

- `MSH`: `MSH-9=ORU^R01^ORU_R01`, `MSH-10` duy nhất theo tenant/client, `MSH-12=2.5.1`.
- `PID-3`: patient identifier; component 4 là assigning authority.
- `PV1-19`: encounter/visit identifier.
- `ORC-2`: placer order identifier.
- `OBR-3`: specimen/accession identifier.
- `OBR-7`: specimen collection DTM.
- Bilirubin `OBX`: `OBX-3` LOINC `1975-2` hoặc `14631-6`; `OBX-5` numeric; `OBX-6` UCUM `mg/dL` hoặc `umol/L`; `OBX-14` observation DTM, fallback `OBR-7`.

## Required local OBX codes

Coding system: `99BILITOOL`.

| OBX-3 code | OBX-2 | Meaning |
|---|---|---|
| `BILI_AGE_HOURS` | `NM` | Tuổi giờ tại thời điểm đo |
| `BILI_GA_WEEKS` | `NM` | Tuổi thai tuần |
| `BILI_PHOTOTHERAPY_STATUS` | `ST` | `none`, `phototherapy`, `intensive-phototherapy`, `stopped` |

Optional boolean OBX values accept `Y`, `1`, `true`, `TRUE`:

- `BILI_IMMUNE_HEMOLYSIS_G6PD`
- `BILI_SEPSIS`
- `BILI_ALBUMIN_LOW`
- `BILI_CLINICAL_INSTABILITY`
- `BILI_JAUNDICE_FIRST_24H`
- `BILI_RH_HEMOLYSIS`
- `BILI_ABO_HEMOLYSIS`
- `BILI_ACUTE_ENCEPHALOPATHY`

## ACK

HTTP response luôn mang HL7 ACK khi message đã qua transport/authentication:

- `MSA-1=AA`: accepted và calculation thành công.
- `MSA-1=AE`: validation/application error; có `ERR`.
- `MSA-2`: echo MSH-10.

ACK thành công có custom segment:

```text
ZBR|resultId|level|phototherapyThreshold|escalationThreshold|exchangeThreshold|mg/dL|guidelineCode|engineVersion
```

Các ký tự HL7 delimiter trong ACK text được escape bằng escape sequences chuẩn.
